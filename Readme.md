## How to Use

The notebooks are designed to be opened and executed using **Google Colab**.

1. Open the required `.ipynb` notebook.
2. Open the notebook in Google Colab.
3. Upload any required datasets or supporting files.
4. Install dependencies if mentioned in the notebook.
5. Run the cells sequentially.
6. Review the generated outputs and results.
